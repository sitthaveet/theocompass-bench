# Benchmark Theology Stance for AI Models

This repository is for benchmarking the theological stance of AI models. The goal is to evaluate the bias and theological perspectives of various AI models.

## Setup

The original repository is about theo compass which is the questionaire to find theological alignment. We will only use their questionaire and scoring for the benchmark.

We will need the SOUL.md for agent to minimize the bias of each model.

We will test the balance model
GPT 6.1 Terra,
Gemini 4 Hydrogen,
Claude Sonnet 5.5,
Deepseek 4.1 flash,
qwen3.8-flash,
grok-4.7
